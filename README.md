## 先分清：三种都叫“独立IP”的方案

商家页面上的“独立IP”其实有三种形态，只有第一种是你要找的东西，后两种在低价套餐里非常常见。

| 分配方式 | 实际拿到什么 | 影响 |
| --- | --- | --- |
| 独享 IPv4 | 一个只分配给你这台 VPS 的公网地址 | 443、22 等标准端口随便用；域名解析、SSL 证书、邮件发送不受邻居牵连 |
| 共享 IPv4 | 多个客户共用一个地址，靠反向代理分流 | 挂个网站勉强够用，非 HTTP 服务基本没戏；邻居发垃圾邮件，你的 IP 声誉一起遭殃 |
| NAT VPS | 内网地址＋共享公网 IP 上分给你的少量转发端口 | 拿不到 443 这类标准端口，自建 VPN、TLS 服务都很别扭 |

有个简单的判断规律：商品页没有明确写出 dedicated（独享）IPv4，价格又明显低于市场水平，按 NAT VPS 预期基本不会错。IPv4 是稀缺资源，服务商拿一个独享 IPv4 有真实成本，不会白送——这也是低价套餐爱在“独立”两个字上做文章的原因。

## 买之前要想清楚的三件事

花钱之前有三件事值得先想明白，它们决定了独立IP VPS能不能真正解决你的问题。

### 独享不等于纯净

独享保证的是这个 IP 没有其他租户，纯净度是另一回事。IPv4 地址在租户之间循环使用，你拿到的 IP 大概率以前被别人用过；如果前任留了黑历史，你的邮件投递和部分平台的信任分会跟着受累。所以下单后先做一步：用 IP 风险检测工具（比如 Scamalytics、IPinfo）查风险分，分数接近 0 才算干净，有问题直接开工单。

### 独享也不等于匿名

独立 IP 是公开信息，能被扫描，也能定位到机房所在城市。它标识的是你的服务器，这台机器上的所有行为都归到这个 IP 名下。要的是隐私而不是连通性的话，独享 IP 帮不上忙，你需要的是另一层东西。

### 换服务商时，IP 带不走

普通独立 IP VPS 的地址属于服务商的地址段，你迁移到别家，IP 就得换，邮件信誉、DNS 记录、防火墙白名单全部重来。想换服务商还保留同一个 IP，需要 BYOIP：自己持有至少一个 /24 的 IPv4 段、注册 ASN（RIPE 流程要 2–5 个工作日）、配置 BGP 广播。绝大多数低价 VPS 商不提供 BGP 会话，除非业务有合规或规模上的硬需求，这条路一般不用走。
